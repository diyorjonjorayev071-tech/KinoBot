# xD KINO Super App V2

Video namunasi asosida qayta ishlangan staging interfeysi.

## Yangi imkoniyatlar
- splash/loading ekrani
- dumaloq tezkor tavsiyalar
- avtomatik hero carousel, strelkalar va indikatorlar
- janr kartalari
- ma'lumotga qarab avtomatik yaratiladigan bo'limlar
- to'liq qidiruv sahifasi va janr filtrlari
- uch bo'limli pastki navigatsiya: Asosiy, Qidiruv, Profil
- profil ma'lumotlari, Telegram ID, balans/obuna statusi
- sevimlilar va tomosha tarixi
- kino tafsilotlari, sifatlar va botga deep-link
- 91 ta kino bazasi bilan orqaga moslik
